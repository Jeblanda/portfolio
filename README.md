# John Benedict A. Landa Portfolio

A static portfolio built with HTML, CSS, and JavaScript. It is ready for Vercel deployment without a build step.

## Deploy to Vercel

1. Push this repository to GitHub.
2. In Vercel, import `Jeblanda/portfolio`.
3. Keep the framework preset as `Other`.
4. Leave the build command empty.
5. Use `.` as the output directory.

Vercel will serve `index.html` from the project root.
